# Noor — Portfolio

A responsive multi-page portfolio built with Next.js App Router, TypeScript, and CSS. Pages are rendered on the server by default and can be deployed to Vercel or any Node.js host.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000. Create a production build with `npm run build` and serve it with `npm start`.

## Personalize

Update the name, biography, project descriptions, and email address in `src/components/Site.tsx` and the page files. Replace the local SVG illustrations in `public/images/` with your own project images when ready.
